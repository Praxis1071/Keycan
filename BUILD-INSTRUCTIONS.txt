KEYCAN FLATPAK BUILD

Keycan, GTK4/libadwaita dönüşümüne hazırlanan mevcut Python/PyQt6 sürümünden bağımsız olarak Flatpak ile paketlenir.

CachyOS/Arch üzerinde:
  sudo pacman -S flatpak flatpak-builder
  flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install flathub org.freedesktop.Platform//26.08 org.freedesktop.Sdk//26.08

Projeyi indirin ve proje dizinine girin:
  git clone https://github.com/Praxis1071/Keycan.git
  cd Keycan

Flatpak'ı derleyip kurun:
  flatpak-builder --user --install --force-clean build-dir org.keycan.Keycan.yml

Çalıştırın:
  flatpak run org.keycan.Keycan

Not: AppImage paketleme araçları ve eski PyInstaller/AppImage betikleri projeden kaldırılmıştır. Keycan'ın dağıtım hedefi Flatpak'tır.
