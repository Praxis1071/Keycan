# Keycan - Linux İçin On Parmak Klavye Uygulaması

**Keycan**, Linux kullanıcıları için geliştirilmiş, klavye kullanım hızını ve doğruluk oranını artırmayı hedefleyen açık kaynaklı bir on parmak klavye pratik uygulamasıdır. 

PyQt6 ve SQLite altyapısıyla geliştirilmiş olup hiçbir ek bağımlılık gerektirmeden `.AppImage` formatında çalışır.

---

## 🚀 Özellikler

* **Bağımlılıksız Çalışma:** `.AppImage` mimarisi sayesinde kurulum gerektirmeden tek tıkla çalışır.
* **Detaylı İstatistikler:** SQLite veritabanı ile yazma hızınızı (WPM/CPM) ve doğruluk oranınızı takip edin.
* **Masaüstü Entegrasyonu:** KDE Plasma ve GNOME dâhil tüm modern Linux masaüstü ortamlarıyla uyumlu tema desteği.

---
